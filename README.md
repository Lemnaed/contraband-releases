# CONTRABAND

100-player anime battle royale, test builds

## Download

Get the latest build from the Releases page:
https://github.com/Lemnaed/contraband-releases/releases/latest

## How to play

1. Download the zip from the latest release and unzip it.
2. Run CuperSontra2.exe.
3. Choose ONLINE, pick a server, then press CONNECT.
4. Choose CREATE TEAM, ENTER CODE, or PLAY SOLO.

The server list ships inside the build.

Windows SmartScreen will warn about the unsigned exe. Click "More info", then "Run anyway".

## Note

This repo holds release downloads only. There is no game source here.
